# 상담 정리 앱 처음 실행 안내

## 처음 설치 순서

1. 압축 파일을 바탕화면에 저장합니다.
2. zip 파일을 마우스 오른쪽 클릭합니다.
3. "모두 추출" 또는 "압축 풀기"를 누릅니다.
4. 압축을 푼 폴더 안으로 들어갑니다.
5. install_first.bat을 더블클릭합니다.
6. 설치가 끝나면 아무 키나 눌러 창을 닫습니다.
7. 이후부터는 run_app.bat을 더블클릭해서 실행합니다.

## 실행 방법

run_app.bat을 더블클릭하면 검은색 창이 열립니다.

잠시 기다리면 브라우저에서 앱이 열립니다.

앱 주소:

http://localhost:8501

브라우저가 자동으로 열리지 않으면 크롬 주소창에 위 주소를 직접 입력하세요.

## 주의사항

- 앱을 사용하는 동안 검은색 창을 닫지 마세요.
- 검은색 창을 닫으면 앱도 꺼집니다.
- 정리본 생성 중에는 브라우저를 새로고침하거나 닫지 마세요.
- 오류가 나면 검은색 창을 닫지 말고 화면을 캡처해서 보내 주세요.
- app.py, data 폴더, requirements.txt는 직접 수정하거나 삭제하지 마세요.

## Codex 관련

이 앱은 정리본 생성에 Codex CLI를 사용합니다.

Codex가 설치되어 있지 않거나 로그인이 안 되어 있으면 정리본 생성이 실패할 수 있습니다.

오류가 나면 PowerShell 창의 오류 메시지를 캡처해서 보내 주세요.

## Google Docs 추가 기능

학생별 Google Docs 추가 기능은 앱 안의 Google Docs 매핑 파일을 기준으로 작동합니다.

Docs 매핑이 없는 학생은 Google Docs 추가가 되지 않을 수 있습니다.

## 로그 CSV → 학생 Docs 추가

1. admin에서 로그 내보내기 CSV를 다운로드합니다.
2. 앱에서 "로그 CSV → 학생 Docs 추가"를 엽니다.
3. CSV를 업로드합니다.
4. 저장 가능 행 전체 선택을 누릅니다.
5. 선택한 기록을 학생 Docs에 추가를 누릅니다.
6. 결과 표에서 성공 / 중복으로 추가하지 않음 / 실패를 확인합니다.

## 필수 파일 누락 오류

앱 화면에 필수 파일 누락 메시지가 뜨면 배포 파일이 일부 빠진 상태입니다.
최신 배포 zip을 다시 받아서 새 폴더에 압축을 풀어 주세요.
압축을 푼 뒤에는 평소처럼 run_app.bat만 더블클릭하면 됩니다.
